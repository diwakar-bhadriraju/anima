# ANIMA Phase I white paper — provenance README

This directory contains the Phase I white paper. It is a paper-writing
artifact: it describes historical experiments and does not modify,
re-run, or reinterpret any frozen record.

## Layout

- `main.tex` — root document (article class; compiles with
  `tectonic main.tex`).
- `references.bib` — bibliography: repository protocol/audit/record
  documents (primary sources) plus standard literature anchors.
- `sections/` — one file per numbered section plus appendices.
- `figures/` — TikZ schematic figures (`fig1-architecture.tex`,
  `fig3-ladder.tex`, `fig8-capmap.tex`) and data figures generated by
  `scripts/`.
- `scripts/` — reproducible figure generation:
  - runs committed repository instrument examples on preserved runs,
  - writes CSVs under `scripts/data/`,
  - draws the data figures (matplotlib, no LaTeX dependency inside).
- `tables/` — standalone LaTeX tables (substrate, phases, findings,
  capability matrix, limitations).

## Claim discipline

Every quantitative claim in the text is traceable to the record listed
above; claims not supported by a record are worded as unmeasured,
unsupported, or speculation. Deviations/defects in the historical
records are preserved and flagged where they affect interpretation
(notably: the V2.1 Stage-C phantom record retracted in the info audit;
the CLLA F2/F6 frozen-window emptiness; the first-exposure allocator
source vacuity; the per-synapse-then-per-neuron cap correction).
